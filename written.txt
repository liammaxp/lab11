Give each sprite a depth value and write that value to the clip-space z coordinate in the vertex shader, then enable GL_DEPTH_TEST and clear the depth buffer each frame. 
The rasterizer will perform depth comparisons automatically, so sprites can occlude each other without manually sorting opaque sprites
